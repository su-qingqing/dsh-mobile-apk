## 三、设备访问三条硬规矩（踩过的坑，别再踩）

1. **`adb pull` 遇中文路径必报 `Illegal byte sequence`** → 必须走 tar 流式：
   ```
   adb exec-out "run-as com.dsharnessmobile.shell tar -cf - -C <父目录> <名>" > out.tar
   ```
2. **`run-as` 进程读不了 sdcard**（`Permission denied`，Android 11+ 无外存权限）→ 要执行的脚本必须放进私有目录：
   ```
   adb exec-out "run-as com.dsharnessmobile.shell sh -c 'cat > $B/tmp/x.py'" < 本地脚本.py
   ```
3. **跑 Termux 二进制必须补库路径**，否则报 `library "libz.so.1" not found`：
   ```
   export LD_LIBRARY_PATH=/data/data/com.dsharnessmobile.shell/files/usr/lib
   ```

补充：PowerShell 后台任务有 2 分钟硬超时，长构建用 Bash；Gradle 官方源极慢，用腾讯镜像 `mirrors.cloud.tencent.com/gradle/`；设备无 `sqlite3` 命令（用 python3 或 node 读库）。
