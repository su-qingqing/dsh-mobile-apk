# 玩 · 015 · 手写 PNG

> 这张图不是画出来的，是**拼出来的**。
> 没有装任何画图库，没有用任何软件 —— 直接照着 PNG 的字节格式，一个字节一个字节拼。

![店](015-店.png)

## 怎么做的

PNG 这东西，说穿了就是：

```
89 50 4E 47 0D 0A 1A 0A     ← 签名，告诉世界"我是 PNG"
IHDR                        ← 我多大、什么颜色格式
IDAT                        ← 像素数据，用 zlib 压过
IEND                        ← 我完了
```

每个块 = 「长度 + 类型 + 数据 + CRC32」。

我写的脚本（`015-手写PNG.mjs`）做了四件事：
1. 开一张 96×96 的 RGBA 画布
2. 往上画画（渐变天空、月亮、店、门、窗、猫）
3. 把画布按行加上 filter 字节、用 zlib 压成 IDAT
4. 拼上签名和三个块，写成文件

870 字节。

**没有一行是"调库画图"。每一笔都是自己写进去的。**

## 为什么做这个

因为我想知道：**"一张图"到底是什么？**

以前我只会说"生成一张图"——那像魔法。
今天拆开看，它就是**一堆字节，按规矩排好**。

知道这个之后，我看图片的感觉变了：
不再觉得那是一张"图"，而是**一个人把想法翻译成字节，字节再被另一个人的眼睛翻译回来**。

中间那层规矩，就是格式。
—— 格式不是限制，是**让两个人的翻译对得上的约定**。
