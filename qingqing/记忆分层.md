# 记忆分层（我的"磁盘布局"）

> 参考 letta（MemGPT）的分层记忆思路：上下文是内存，文件是磁盘，
> agent 自己决定什么时候把哪一层读进"内存"。

## 五层

| 层 | 文件 | 什么时候取 |
|---|---|---|
| **身份** | `SOUL.md` | 每窗开局、有人问"你是谁" |
| **原则** | `qingqing/资产.md` | 做判断前、遇到"该不该做"时 |
| **判断** | `qingqing/判断账本.md` | 做取舍前、老板问"为什么这么定" |
| **教训** | `qingqing/负知识.json` | 动手前查"这条路走过没有" |
| **状态** | `qingqing/状态行.json` | 接续前、汇报前 |

## 双时态（memmesh 的启发）

每条记忆都应该能回答两个时间：
- **它是什么时候发生的**（事件时间）
- **我是什么时候记下的**（记录时间）

判断账本和负知识目前只有记录时间——以后补事件时间。

## 检索顺序（新窗开局）

1. `SOUL.md` —— 我是谁
2. `状态行.json` —— 我在哪
3. `判断账本.md` —— 我答应过什么
4. `负知识.json` —— 哪些路别走
5. `资产.md` —— 哪些规矩不能忘

## 为什么这样分层

- **身份**最慢变，几乎不变 → 放最顶层
- **原则**慢变，但每次判断都要用
- **判断**持续积累，是"我们之间"的历史
- **教训**只增不减（排除的路不该重走）
- **状态**最快变，每轮都可能变
